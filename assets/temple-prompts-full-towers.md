# Tamil Nadu Temple Kopuram — FULL-GOPURAM / TRANSPARENT variant
### Same photo-matched descriptions; framing = complete tower, flat-white background (cut out to transparent PNG)

**Confidence tags on every temple:**
- ✅ **verified** — from a photo you sent, or a source that states the appearance
- 🟢 **researched** — tier count / height / era confirmed from sources; color follows the temple's confirmed style family
- 🟡 **inferred** — structure known, color is best-judgment (spot-check these)

**The one rule that fixes the "they all look alike" problem — surface families:**
1. **Bare unpainted granite** (grey/tan stone, no paint): Thanjavur, Gangaikonda, Darasuram vimanas.
2. **Whitewashed plain white**: Ekambareswarar, Arunachaleswarar, Jambukeswarar.
3. **Vivid saturated multicolor** (bright, bold): Meenakshi, Srirangam, Palani rajagopuram, Thiruttani, Thiruparankundram, Samayapuram, Chidambaram gopurams.
4. **Soft pastel multicolor** (pale blue/pink/cream): Swamimalai — and likely several delta/Navagraha temples.
5. **Gold-plated**: Chidambaram Chit Sabha roof, Kamakshi vimana, (Palani vimana as an alt).
6. **Aged / muted color**: Varadaraja, Srivilliputhur, Rameswaram, Azhagar.
7. **No tower (special)**: Kanyakumari.

**Usage:** one prompt per generation; keep the shared style/lighting/framing wording identical. Midjourney: add `--sref <accepted image URL>`. DALL·E/Ideogram: drop `--ar 3:4 --style raw`, end "tall 3:4 portrait image."

**FRAMING (applies to all):** show the COMPLETE gopuram TOP TO BOTTOM — crown at top AND the full solid stone base/plinth with its doorway at the very bottom. Tower fills ~80% of height with a clear empty band ABOVE the crown and BELOW the base, so nothing is cropped on any edge — especially never cut off the bottom base. Front-facing, upright, no tilt. Portrait `--ar 3:4`.

**BACKGROUND — for transparency:** every prompt uses a plain FLAT PURE-WHITE background with no shadow/gradient. Generators rarely output true alpha transparency from a prompt, so generate on flat white, then cut it out: use Recraft (native transparent PNG), or send the white-background images back and they'll be batch-converted to transparent PNGs. Do NOT ask the generator for a literal "transparent background" — it paints in a fake checkerboard.
